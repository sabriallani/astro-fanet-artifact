# Repository Scope

This repository intentionally preserves enough upstream ns-3 and NetAnim source to keep the A3D-BSM scenario buildable from source on macOS.

Included:

- ns-3.29 source tree
- custom `astro-fanet` ns-3 module containing the A3D-BSM implementation
- simulation scenario and helper scripts
- NetAnim source tree

Excluded from version control:

- build outputs
- generated simulation results
- temporary files
- compiled NetAnim binary
- object files
