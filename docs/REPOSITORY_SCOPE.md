# Repository Scope

This repository intentionally preserves enough upstream ns-3 and NetAnim source to keep the ASTRO-FANET scenario buildable from source on macOS.

Included:

- ns-3.29 source tree
- custom ASTRO-FANET module
- simulation scenario and helper scripts
- NetAnim source tree

Excluded from version control:

- build outputs
- generated simulation results
- temporary files
- compiled NetAnim binary
- object files
